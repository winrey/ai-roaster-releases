# AI Roaster

[简体中文](README.md) · [English](README.en.md) · **日本語**

**すべての利用枠を、ひと目で把握。**

個人向けの AI サブスクリプション利用状況ダッシュボードです。Codex、Claude デスクトップアプリ、Claude Code のアカウント、残りの利用枠、利用履歴をまとめて確認し、ローカルでアカウントを切り替えられます。

[ダウンロードと更新履歴](https://github.com/winrey/ai-roaster-releases/releases) · [macOS インストールガイド](INSTALL.ja.md) · [問題を報告](https://github.com/winrey/ai-roaster-releases/issues)

## ダウンロードと更新

Releases でバージョンを選び、`YuHuo-AI-Roaster_<バージョン>_macOS_universal.dmg` をダウンロードしてください。ユニバーサルインストーラーには Apple シリコンと Intel の両アーキテクチャが含まれます。各リリースにはインストール手順、ビルド情報、SHA-256 チェックサムが付属します。

現在の推奨版は [0.2.12 正式版](https://github.com/winrey/ai-roaster-releases/releases/tag/v0.2.12)です。署名、公証、検証の結果はこのリリースの `BUILD-INFO.txt` / `NOTARIZATION.json`、ファイルのチェックサムは `SHA256SUMS.txt` を確認してください。過去のバージョンの検証状況は、それぞれのリリースを確認してください。Intel Mac での実機検証は未実施です。

画面表示は日本語、簡体字中国語、英語に対応し、初期設定ではシステム言語に合わせます。手動で選ぶ場合は、**設定 → 一般 → 言語**で選択し、**設定を保存**をクリックしてください。選択した言語が反映され、次回以降も保持されます。アプリ内の名称は中国語では **余火**、英語と日本語では **AI Roaster** です。Finder と Dock の名称は macOS の言語設定で個別に決まり、システムがアプリを再認識した後に更新される場合があります。

v0.2.5 から、macOS でアプリ内更新を利用できます。アプリメニューの **更新を確認** は公開リリースリポジトリを参照し、既定では正式版のみを確認します。プレリリースを含めることもできます。自動確認と自動ダウンロードは既定で有効です。署名付き更新パッケージがある新版を検出すると、バックグラウンドでダウンロードして署名を検証します。インストールと再起動は、利用者が **再起動して更新** をクリックした時に行います。

自動確認と自動ダウンロードは個別に設定できます。自動確認をオフにすると、バックグラウンドでのダウンロードも停止します。手動での確認とダウンロードは引き続き利用できます。署名付きのアプリ内更新パッケージがないリリースは、公開ページから DMG をダウンロードして手動でインストールできます。

**v0.2.4 以前から更新する場合は、最初に一度だけ v0.2.5 以降を手動でインストールしてください。その後はアプリ内更新を利用できます。**

## 機能

- Codex、Claude デスクトップアプリ、Claude Code のローカルログインの検出、利用枠の取得、アカウント切り替え。
- 複数アカウントと複数の利用枠期間、手動補正、履歴グラフ。
- サブスクリプションの有効期限、Credit 残高と残高履歴、アカウントタグ、タグ検索。
- ライト、ダーク、システム連動のテーマと、すりガラス効果の透明度調整。
- macOS メニューバー、ログイン時の自動起動、ローカル JSON のインポートとエクスポート。

デスクトップクライアントのアカウントを切り替えると、そのクライアントが終了して再起動するため、実行中のタスクは中断されます。Claude のログイン全体、実際の利用枠の取得、双方向のアカウント切り替えについては、さらに実機での検証が必要です。

## データとフィードバック

アカウント、利用枠の履歴、認証情報は利用者のコンピューターに保存されます。インストーラーに開発者のアカウントデータは含まれません。更新確認に GitHub トークンは不要で、メールアドレス、認証情報、利用枠の記録をアップロードすることもありません。

問題を報告する際は、OS、チップの種類、アプリのバージョン、再現手順を記載してください。スクリーンショットの個人情報は隠し、認証ファイルやデータディレクトリ全体はアップロードしないでください。

このリポジトリは、公開インストーラー、更新履歴、問題報告のためのものです。アプリのソースリポジトリは非公開です。プロジェクトのオープンソースライセンスは指定されていません。
